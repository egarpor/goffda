# Plan: S3 class system for `goffda` (v0.2.0)

## Context

`goffda` (0.1.2 on CRAN, 2023-10-14) is being prepared for submission
to the R Journal. The package has ~5000 lines (R + C++ via
Rcpp/RcppArmadillo) and exposes 25 functions, but **does not use S3
classes**: `flm_est`, `cv_glmnet` return plain lists; `fpc` already
has `class<-"fpc"` but no methods; and `flm_test` returns an `htest`
object with ~90 lines of inline plotting code (`R/flm_test.R:850-941`)
that belong in a `plot.flm_test`.

The R Journal expects an idiomatic R API:
`print/summary/plot/coef/predict/fitted/residuals` defined. This
release introduces that system **without breaking `$` access to the
return fields** (the 27+ internal accesses in `flm_est` and the
bootstrap accesses in `flm_test` keep working) and refactors
`flm_test` plotting along a clear deprecation path.

## Decisions agreed with the user

1. **`flm_test` plotting migration**: deprecate `plot_proc` /
   `plot_dens` with `warning()` ("argument deprecated; use `plot()` on
   the returned object"). Keep them in the signature with default
   `FALSE` so existing calls do not error; if `TRUE`, emit warning,
   call the extracted helper internally, and continue. Removal
   scheduled for 0.3.0.
2. **`predict.flm_est`**: cover the four branches (X
   functional/scalar × Y functional/scalar). The method dispatches by
   inspecting `scalar_X` / `scalar_Y` flags stored in the fitted
   object.
3. **`vcov.flm_est`**: NOT implemented. Uncertainty is provided by
   `flm_test()` via bootstrap; document this in the paper.
4. **Version**: bump to `0.2.0`.

## Organisation convention

S3 methods are appended **at the end of the constructor's file**,
following the tidyverse / r-lib convention. No `R/s3-*.R` files are
created. Only tests live in separate files (testthat convention).

## Files created

- `tests/testthat.R` (testthat bootstrap).
- `tests/testthat/test-fpc.R`, `test-flm_est.R`, `test-cv_glmnet.R`,
  `test-flm_test.R` (one test file per source file, matching
  `usethis::use_test()`). Each file groups constructor and S3 method
  tests.

## Per-class design

### `fpc` (end of R/fpc.R)
- `print.fpc(x, ...)` — header + n_fpc + argvals range + cumulative
  variance.
- `summary.fpc(object, ...)` — returns `"summary.fpc"` with `d^2`,
  proportion and cumulative proportion; `print.summary.fpc` formats it
  (style of `summary.prcomp`).
- `plot.fpc(x, ind = seq_len(min(3, length(x$l))), ...)` — two-panel:
  screeplot + eigenfunctions via `fda.usc::plot.fdata`.
- `predict.fpc(object, newdata, int_rule = "trapezoid", ...)` — projects
  new curves onto the stored eigenfunctions using `w_integral1D`
  (already exported). Validates that `newdata$argvals` matches
  `object$rotation$argvals`.

### `flm_est` (end of R/flm_est.R)
- `print.flm_est(x, ...)` — method, `length(p_hat)` / `length(q_thre)`,
  `lambda` if non-NULL, RSS if `Y_hat` non-NULL.
- `summary.flm_est(object, ...)` — adds R²-like `1 - SS_res/SS_Y`
  computed in scores; CV summary if present.
- `coef.flm_est(object, type = c("matrix", "scores"), ...)`.
- `fitted.flm_est(object, type = c("response", "scores"), ...)` — errors
  if `compute_residuals=FALSE` (NULL fields).
- `residuals.flm_est` — symmetric to `fitted`.
- `predict.flm_est(object, newdata = NULL, type = c("response",
  "scores"), int_rule = "trapezoid", ...)` — without `newdata` delegates
  to `fitted()`. With `newdata`, dispatches to four branches via
  `scalar_X` / `scalar_Y` flags:
  - X functional → `predict.fpc(object$X_fpc, newdata)` for new scores.
  - X scalar → use `newdata` as a column matrix (centred with its own
    mean to match the training pipeline).
  - Y functional → reconstruct via `fpc_to_fdata(scores, fpc=object$Y_fpc)`.
  - Y scalar → `drop()` to a numeric vector.
- `plot.flm_est(x, ...)` — `image()` of `Beta_hat` with
  `viridisLite::viridis` (graceful fallback to `grDevices::hcl.colors`)
  for the X/Y functional case; line plot for scalar branches.

### `cv_glmnet` (end of R/cv_glmnet.R)
- `print.cv_glmnet` — `lambda`, dim of `beta_hat`, intercept fitted, CV
  used.
- `coef.cv_glmnet(object, intercept = TRUE, ...)`.
- `predict.cv_glmnet(object, newx, ...)` — `newx %*% beta_hat` swept by
  `intercept` along columns.
- `plot.cv_glmnet(x, ...)` — if `!is.null(x$cv)`, delegate to
  `plot(x$cv)` (dispatches to `glmnet:::plot.cv.glmnet` because the
  inner object keeps its original class); otherwise `plot(x$fit)`.

### `flm_test` (end of R/flm_test.R)
- Subclass `c("flm_test", "htest")` → `print` inherited from `htest`
  (correct).
- `summary.flm_test` — adds `mean` / `sd` / `median` of
  `boot_statistics`, dimensions used.
- `plot.flm_test(x, type = c("dens", "proc", "both"), plot_max_p = 2,
  plot_max_q = 2, ...)` — refactor of the inline block. Requires
  `x$fit_flm` and `x$boot_statistics` non-NA (informative error if
  pruned).
- Non-exported helper `plot_flm_test_internal()` with the shared
  logic.
- The result now stores `boot_E_scores`, a 3-D array of bootstrap
  residual FPC scores (shape `n × q × min(plot_max_procs, B)`),
  populated cyclically during the bootstrap and consumed by the
  `"proc"` plot. Set to `NA` when `save_boot_stats = FALSE`.

## Existing functions to reuse (do not reimplement)

- `fpc_to_fdata()` — `R/fpc.R:424` — reconstructs fdata from scores.
- `fpc_to_beta()` — `R/fpc.R` — reconstructs Beta from
  `Beta_hat_scores`.
- `fpc_coefs()` — exported — projects an `fdata` onto FPC
  eigenfunctions; reused inside `predict.fpc`.
- `inprod_fdata()`, `w_integral1D()` — exported.
- `fda.usc::plot.fdata` — already imported in NAMESPACE — reused for
  `plot.fpc` and the functional branch of `plot.flm_est`.

## Test plan (testthat, key cases per file)

Each file covers the constructor + its S3 methods.

- `test-fpc.R`:
  - Constructor: `fpc()` returns a structure with all expected fields.
  - Class `"fpc"` assigned.
  - `predict(fpc(X), newdata = X)` ≈ `fpc(X)$scores` (round-trip).
  - `plot.fpc` does not error.
  - `summary.fpc`: `cumsum(prop)` ends at 1 (numerical tolerance).
- `test-flm_est.R`:
  - Constructor: the four branches (X fdata/numeric × Y fdata/numeric)
    produce a valid object with coherent fields.
  - Class `"flm_est"` assigned.
  - `predict(fit, newdata = X)` ≈ `fitted(fit)` in all four branches.
  - `predict` with new curves/values returns the right type and
    coherent length.
  - `fitted()` errors if `compute_residuals = FALSE`.
  - `coef` / `residuals` return the right fields.
- `test-cv_glmnet.R`:
  - Constructor: `cv_glmnet()` runs CV and returns a sensible
    `lambda`.
  - Class `"cv_glmnet"` assigned.
  - `predict(cv, newx)` matches manual `newx %*% beta_hat + intercept`.
- `test-flm_test.R`:
  - Constructor: `flm_test()` with small `B` and a fixed seed returns
    a reproducible `p.value`.
  - `inherits(out, c("flm_test", "htest"))`.
  - `print(out)` produces output (smoke test, capture).
  - `plot(out, type = "dens")` / `"proc"` do not error.
  - Calling `flm_test(..., plot_dens = TRUE)` emits
    `warning("...deprecated...")`.

## Execution order

Strategy chosen with the user: **implementation first, all tests at
the end in a single block**.

1. **Implementation block** (no tests):
   1. `R/fpc.R`: append `print` / `summary` / `plot` / `predict`.
   2. `R/cv_glmnet.R`: wrap return + `print` / `coef` / `predict` /
      `plot`.
   3. `R/flm_est.R`: wrap return + `print` / `summary` / `coef` /
      `fitted` / `residuals` / `predict` (4 branches) / `plot`.
   4. `R/flm_test.R`: subclass `c("flm_test", "htest")`, deprecate
      `plot_proc` / `plot_dens`, helper `plot_flm_test_internal()`,
      `summary.flm_test`, `plot.flm_test`.
   5. `devtools::document()` to regenerate NAMESPACE and `man/*.Rd`.
   6. Quick manual verification: load the package, run key
      `@examples`, check that `R CMD check` does not break.

2. **Test block** (all at the end):
   1. `usethis::use_testthat()` → generates `tests/testthat.R`.
   2. Write the four `tests/testthat/test-<fn>.R` files with all
      cases of the test plan.
   3. `devtools::test()` until green.
   4. Acknowledged risk: critically review that tests are not just
      "validating what was written" but actual expected behaviour
      (especially `predict` for the four branches — compare against
      independent manual computations, not against the method's own
      output).

3. **Closing block**:
   1. Update `NEWS.md` with `# goffda 0.2.0` block.
   2. Bump `Version: 0.2.0` and `Date:` in `DESCRIPTION`.
   3. Update `cran-comments.md`.
   4. README.Rmd showcase of `predict(fit, newdata = )` and
      `plot(test_out)`; recompile to `README.md`.
